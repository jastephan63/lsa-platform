# Synthetic dataset specification

> **All data in this project is synthetic.** Every school, student, response,
> and weight is generated by [`r/datagen/generate.R`](../r/datagen/generate.R)
> from a fixed random seed. No real person-level data is used anywhere, and no
> generated record corresponds to a real person or school.

## Generation model

The generator mimics the *shape* of a Swiss large-scale assessment sample
without claiming statistical fidelity to any real survey:

1. **Population frame** — ~800 fictional schools distributed over the 26
   cantons proportionally to a rough population share. The canton → language
   region mapping (de/fr/it) is public knowledge; everything else is invented.
   School sizes are log-normal.
2. **First stage** — within each canton (the stratum), schools are drawn by
   systematic PPS sampling (probability proportional to school size).
   `school_weight = 1 / inclusion_probability`.
3. **Second stage** — 20 students per sampled school (or all, if smaller),
   drawn with equal probability. The design weight multiplies the two stages.
4. **Nonresponse** — participation is Bernoulli with a per-canton rate in
   [0.82, 0.98]. Responder weights are inflated within the canton so each
   canton's weighted total is preserved (`final_weight`); an invariant check
   in the script fails the run if this does not hold.
5. **Item responses** — 30 dichotomous items under a Rasch model. Ability is
   normal with small canton, language-region, and SES effects. Non-participants
   have no response records.
6. **Plausible values** — five per responder, drawn from an EAP posterior
   computed on an 81-point quadrature grid from the student's actual response
   pattern, then linearly rescaled to a familiar mean-500/SD-100 reporting
   scale. This is a deliberate simplification of operational PV methodology
   (no conditioning model, no multidimensionality); it exists so the analysis
   layer has realistically-shaped inputs, not to demonstrate psychometrics.

## Files (`data/raw/`, gitignored; regenerate with `make data`)

### `schools.csv`
| Column | Type | Notes |
| ------ | ---- | ----- |
| school_id | text, PK | `SCHnnnn`, synthetic identifier |
| canton | text | two-letter canton code |
| language_region | text | `de`, `fr`, or `it` |
| n_students | int | frame size of the school |
| incl_prob | numeric | first-stage inclusion probability, (0, 1] |
| school_weight | numeric | 1 / incl_prob |

### `students.csv`
| Column | Type | Notes |
| ------ | ---- | ----- |
| student_id | text, PK | `STUnnnnn`, synthetic identifier |
| school_id | text, FK → schools | |
| canton, language_region | text | denormalised from the school for convenience; ingestion re-checks consistency |
| sex | text | `f` / `m` |
| ses_quintile | int | 1–5 |
| participated | bool | nonresponse flag |
| student_weight | numeric | two-stage design weight |
| final_weight | numeric | nonresponse-adjusted; NULL for non-participants |

### `items.csv`
| Column | Type | Notes |
| ------ | ---- | ----- |
| item_id | text, PK | `ITnn` |
| difficulty | numeric | Rasch difficulty used for generation |
| domain | text | reading / math / science |

### `responses.csv`
| Column | Type | Notes |
| ------ | ---- | ----- |
| student_id | text, FK | responders only |
| item_id | text, FK | |
| correct | int | 0/1 |

### `plausible_values.csv`
| Column | Type | Notes |
| ------ | ---- | ----- |
| student_id | text, FK | responders only |
| pv1 … pv5 | numeric | reporting scale, mean ≈ 500, SD ≈ 100 |

### `manifest.csv`
Key–value record of the seed, generation timestamp, and row counts. The
timestamp is the only non-reproducible field; everything else is
byte-identical across runs with the same seed (asserted in CI).

## Identifiers and data protection

Identifiers are sequential synthetic codes with no linkage to any real entity.
In a real deployment these would be pseudonyms issued by a trusted third
party; see [datenschutz.md](datenschutz.md) for how this platform treats
identifying data by design.
