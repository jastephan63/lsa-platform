# Security policy

This is a demonstration project without production deployments or real
data, so there is no coordinated-disclosure machinery behind it. Still:

- If you find a security problem, open a GitHub issue, or email
  jake@stephan-j.com if it should not be public.
- Expect an answer within a few days; this repository is maintained by one
  person as a portfolio project.

The security design itself — threat model, least privilege, secrets
handling, scanning — is documented in [docs/security.md](docs/security.md).
